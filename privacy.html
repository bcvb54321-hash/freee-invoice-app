プライバシーポリシー（freee請求書連携）

制定日：2026年10月17日

1. このアプリについて

「freee請求書連携」（以下「本アプリ」）は、NALU DREAM が社内の請求業務のためだけに使う Google Apps Script のツールです。利用者は NALU DREAM の管理者アカウントに限られます。

2. 利用する Google のデータ

  • Google スプレッドシート：請求データの読み取りと、送付・入金状況の書き込み
  • Google ドライブ：請求書 PDF の保存と共有リンクの作成
  • Gmail：社内向けのお知らせメールの送信と、関連メールの確認
  • 外部サービスへの接続：freee（請求書・入金の確認）と LINE（担当者へのお知らせ）

3. 利用の目的

請求書の作成・送付、入金の確認、担当者へのお知らせという社内の請求業務にだけ使います。広告や、それ以外の目的には使いません。

4. 第三者への提供

取得したデータを売ったり、第三者に渡したりしません。請求業務に必要な範囲で、freee と LINE にのみデータを送ります。

5. 保管

データは NALU DREAM の Google アカウント内（スプレッドシート・ドライブ）に保管し、業務に必要な期間だけ保持します。

6. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から受け取った情報の使用と移転は、「限定的な使用」の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。
